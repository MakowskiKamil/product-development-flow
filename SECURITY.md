# Security

Report a vulnerability privately: on GitHub, open this repo's **Security** tab and choose **Report a vulnerability**. Please do not open a public issue for it.

There is no bounty. This is a one-maintainer project, so responses are best effort, with no promised response time.

Worth reporting: anything that lets a repo, a playbook, a Linear issue or a PR make `flow` or the keeper run a command it should not, write outside the state dir, a session's worktree or the files it names, or leak a private file into the repo or a public CI log.
